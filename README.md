# Fade

> 흐려지기 전에, 적어두기.

키보드로 먼저 쓰고, 종이 다이어리에 손으로 옮겨 쓰는 사람을 위한 일기장.
기억이 사진처럼 바래듯이, **종이에 옮겨 쓰지 않은 날의 기록은 조금씩 바랩니다.**

## 화면

| 화면 | 설명 |
| --- | --- |
| 표지 | 가죽 바인더 표지. `펼치기`로 오늘 페이지를 엽니다. |
| 오늘 펼침면 | 왼쪽: 날짜 티켓 · 사진 포켓(네거티브 → 눌러서 현상) · 노출(기분) · 할 일 쪽지<br>오른쪽: 줄 노트 일기 · 회고 세 줄 · 오늘을 정착하기 |
| 한 주 밀착 인화 | 왼쪽: 7일 필름 밀착 인화 · 색연필로 고르는 이번 주의 한 컷<br>오른쪽: 하루 한 줄 · 옮겨 썼어요 토글 · 이번 주 회고 |

## 바래짐 규칙

- 오늘은 바래지 않습니다.
- 하루가 지날수록 사진은 색이 빠지고 글씨는 흐려집니다. (14일이면 완전히 바램)
- **정착**하면 절반 속도로 바랩니다.
- **옮겨 썼어요**를 누르면 더 이상 바래지 않고 선명해집니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl` + `←` / `→` | 어제 / 내일 (글 입력 중이 아닐 때) |
| `Ctrl` + `Enter` | 오늘을 정착하기 |
| `Ctrl` + `Shift` + `E` | 회고로 이동 |
| `Ctrl` + `V` | 사진 붙여넣기 (끌어다 놓기도 가능) |

## 구조

```
fade/
├── apps/
│   └── web/            # React + Vite (PC 웹, 이후 Tauri·PWA로 감쌀 예정)
└── packages/
    ├── core/           # 타입, 날짜 유틸, 노출(기분), 바래짐 계산
    └── ui-tokens/      # 색 · 폰트 · 그림자 디자인 토큰
```

## 시작하기

```bash
pnpm install
pnpm dev        # http://localhost:5173
```

지금은 브라우저 `localStorage`에만 저장합니다. 사진은 긴 변 1000px JPEG로 줄여 저장해요.

### 환경변수

기기 간 동기화를 붙일 때 필요합니다. 지금은 없어도 동작해요.

```bash
cp apps/web/.env.example apps/web/.env.local
```

`.env*` 파일은 커밋되지 않습니다.
